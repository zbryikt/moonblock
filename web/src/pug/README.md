# 擲筊 Moon Blocks 3D 模擬器

使用 Three.js + Cannon.js 開發的 3D 擲筊模擬器，具備真實物理效果、互動式 3D 視角與擬真音效。

![Cover](https://via.placeholder.com/800x400?text=Moon+Blocks+3D)

## 🌟 主要特色

*   **真實物理模擬**：整合 `cannon-es` 物理引擎，精確模擬重力、碰撞、摩擦與彈跳，呈現最自然的擲筊動態。
*   **3D 視覺效果**：
    *   使用 `.glb` 模型，自動校正幾何重心。
    *   **雙色呈現**：根據材質名稱自動識別平面（木頭色/白色）與凸面（紅色）。
    *   **光影系統**：多光源配置，半透明陰影材質 (`ShadowMaterial`)，在透明背景上也能呈現立體感。
    *   **運鏡特效**：擲筊時鏡頭自動環繞旋轉，增加戲劇張力。
*   **擬真音效**：
    *   內建 4 組真實錄製的擲筊音效 (`.mp3`)。
    *   基於物理碰撞觸發，每個筊杯在單次擲筊中只會觸發一次主要音效，模擬真實落地聲響。
*   **現代化介面 (RWD)**：
    *   **統計儀表板**：即時顯示聖筊、笑筊、陰筊的累積次數。
    *   **響應式設計**：完美支援桌面與手機版操作。
    *   **透明背景**：Canvas 背景透明，可融入任何網頁設計。

## 🛠 技術架構

### 前端框架
- **模板引擎**: Pug
- **樣式**: Stylus
- **JavaScript**: ES Module
- **3D 引擎**: Three.js 0.160.0
- **物理引擎**: Cannon-es 0.20.0

### 檔案結構
```
moonblock/
├── index.js            # 核心邏輯 (Three.js 場景, Cannon.js 物理, UI 互動)
├── index.pug           # HTML 結構與 Import Maps
├── index.styl          # CSS 樣式 (RWD, Flexbox 佈局)
├── moonblock-data.js   # Base64 編碼的 GLB 模型資料
├── build-model-data.sh # 用於將 .glb 轉為 .js 的腳本
├── sound-1~4.mp3       # 音效素材
└── README.md           # 專案說明文件
```

## 🚀 開發歷程與技術細節

### 1. 物理系統優化 (Physics)
*   **ConvexPolyhedron**: 為了解決複雜模型導致的物理穿透與效能問題，我們手動定義了一個 8 頂點的 **楔形凸多面體 (Wedge-shaped ConvexPolyhedron)** 來近似筊杯形狀。
    *   精確定義了 12 個三角形面，並嚴格遵守 **逆時針 (CCW)** 頂點順序，確保法線朝外。
    *   **重心校正**: 在載入模型時，自動計算幾何中心並歸零，確保物理旋轉中心與視覺中心一致。
*   **參數調校**:
    *   **重力**: `-20` (增強下墜感)。
    *   **彈性 (Restitution)**: `0.8` (高彈性)。
    *   **摩擦力 (Friction)**: `0.1` (低摩擦，易滑動)。

### 2. 材質與視覺 (Visuals)
*   **雙色識別**: 程式會掃描 GLB 模型中的材質名稱：
    *   含 `flat` 關鍵字 -> 染成 **白色/木頭色**。
    *   含 `curve` 關鍵字 -> 染成 **紅色**。
*   **陰影優化**:
    *   使用 `ShadowMaterial` (`opacity: 0.3`) 取代實體地板，只顯示半透明陰影，達成透明背景效果。
    *   只保留主光源 (`spotLight1`) 投射陰影，避免多重影干擾。

### 3. 音效系統 (Audio)
*   **觸發邏輯**: 監聽 `collide` 事件。
*   **單次觸發機制**: 為了配合長達 1 秒的完整錄音素材，每個筊杯在一次擲筊流程中，只會在 **第一次強力撞擊 (Velocity > 1.0)** 時播放一次音效。我們修正了 `collide` 事件中 `e.body` (對方) 與 `e.target` (自己) 的誤用，確保每次擲筊的新物體都能正確發聲。
*   **隨機性**: 隨機挑選音效檔，並微調 `playbackRate` (0.95~1.05) 與 `volume`，讓聲音更自然。

### 4. 介面設計 (UI/UX)
*   **統計儀表板**: 取代傳統列表，直接顯示三大結果（聖筊/笑筊/陰筊）的累積次數與 Emoji，支援手機版響應式佈局。
*   **運鏡/地板開關**: 提供 Checkbox 切換「運鏡特效」，開啟時會顯示地板陰影並啟用相機旋轉；關閉時保持定點視角與透明背景。
*   **全螢幕結果**: 擲筊結束後顯示大字的結果與 Emoji，點擊任意處關閉。

## 📦 如何執行

1.  **準備環境**: 確保有靜態網頁伺服器 (如 `Live Server`, `http-server`, 或 `python -m http.server`)。
2.  **編譯 Pug/Stylus** (如果需要開發):
    ```bash
    # 假設有安裝 pug-cli 和 stylus
    pug index.pug
    stylus index.styl
    ```
3.  **模型轉換**: 如果更換了 `moonblock.glb`，請執行：
    ```bash
    ./build-model-data.sh
    ```
4.  **啟動**: 打開瀏覽器瀏覽 `index.html`。
